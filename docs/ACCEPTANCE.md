## 3. 发行与启动

在目标 Mac 上安装 Rust stable、Node.js/npm 和 CPython 3.11 后，首次联网准备锁定依赖并构建：

```sh
./run.sh prepare
./run.sh build
./run.sh start
```

浏览器访问 `http://127.0.0.1:8080/`。停止全部本机服务及 Rust 管理的 Python 任务进程：

```sh
./run.sh stop
```

`prepare` 负责获取依赖；发行构建 `build` 使用锁文件和本机缓存离线执行。启动不需要 Node.js 或 Cargo，只需要兼容的 CPython 3.11 解释器；若解释器命令不是 `python3.11`，启动时设置 `SCHED_PYTHON_BIN`。
